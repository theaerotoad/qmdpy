Query Cheat Codes

                    
Embed power directives right into your search box to instantly steer searches.

                

                

                    

                        
                            

                                Directive
                                Target Field / Action
                                Example
                            

                        
                        
                            

                                title:"..."
                                Document Title Filter
                                title:"Deep Space" orbit
                            

                            

                                file:"..." / path:...
                                File or Directory Path
                                file:guide.md markdown
                            

                            

                                col:... / in:...
                                Target Collection
                                in:Books propulsion
                            

                            

                                lex:"..." / fts:"..."
                                Strict BM25 Lexical Term
                                lex:"vector math" similarity
                            

                            

                                pii:off / pii:on
                                Toggle PII Redaction
                                pii:off contact info
                            

                            

                                seen:exclude / seen:off
                                Toggle Exclude Seen
                                seen:exclude apollo mission
                            

                            

                                rerank:on / rerank:off
                                Toggle LLM Reranking
                                rerank:on quantum mechanics
                            

                            

                                limit:N
                                Result limit count
                                limit:25 telemetry
